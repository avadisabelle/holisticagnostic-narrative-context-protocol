## Purpose

This packet provides the academic grounding for how oral traditions encode, validate, and transmit narrative knowledge — and how the storywork framework provides a protocol for story transmission that is not document-based.

The central insight: **oral traditions already ARE protocols — they just aren't written in JSON.**
