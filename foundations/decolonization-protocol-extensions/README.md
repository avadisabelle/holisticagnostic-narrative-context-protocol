## Purpose

This packet provides a decolonial analysis of the Narrative Context Protocol (NCP) and proposes concrete protocol extensions that would allow the NCP to support Indigenous and non-Western narrative knowledge systems without extracting or flattening them.

The central argument: **the NCP currently models what a story contains, but not the conditions under which a story may travel. To support Indigenous and non-Western narrative traditions, the protocol must be extended to express transmission conditions, relational provenance, linguistic framing, performativity, and semantic access control — without reducing those systems to extractable JSON fields.**
